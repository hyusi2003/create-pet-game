# 导入即时生效与热更新避坑

用户要求制作形象/游戏并接入产品时，完成「转换 → 当前客户端导入 → 列表可见 → 按授权应用/打开 → 实际画面验证」。不要在生成图片、HTML、素材包或写入磁盘后结束。用户仅要独立文件时交付文件；未授权换装时只收藏。以下核对于 2026-10-16；入口名称变化时以目标客户端实际入口为准。

## 先辨认目标与产物

- 找到用户要用的正在运行的客户端及其实际资料目录、源码/安装来源；存在多实例时不能凭仓库路径猜目标。不同时启动两个共享 userData 的进程。
- 形象按 [形象接入](appearance-import.md) 转成合法外观包。普通 HTML（包括 Scratch 导出的网页）、预览 manifest 和实时 3D 包不能冒充 2D 形象包。
- HTML 从现有作品预览/文件入口导入，即可打开；需要出现在游戏库时另按 [游戏目录登记](product-import.md) 完成资源、完整目录与摘要接入。这是两个交付结果，不能互相代替。

## 形象：从当前客户端登记并应用

1. 在目标客户端打开「伙伴外观 → 导入形象」，选择合法 `character.json` 或 `.petappearance`。自动化可在该受信页面通过真实文件输入完成同一路径；制作工具不可直接调用原始 IPC 或把宿主私有接口塞进 HTML。
2. 阅读逐文件返回的 `imported/errors` 与页面反馈，确认新条目、正确缩略图、动作和名称；`ok:true` 仍可能包含某些文件的 errors。重复相同内容沿用库记录，更新字节后使用本次实际返回的 id，不能按名称猜 id 或继续应用旧版。
3. 已授权换上时在同一运行客户端点击「使用形象」（旧版为「用这个形象」）。等待真实桌宠加载本次帧，核对关键动作、帧变化、朝向及伙伴身份/名字/人设保持。导入收藏不会自动换上。保存成功/派发成功不能替代渲染成功。
4. 同一个进程内再次导入修改后的包并应用，证明新帧生效。无需重启桌宠；外观导出后用隔离新实例另验持久化，重启只是额外测试，不是用户生效步骤。

补动作时保留其他已验收动作及原分辨率。探头后的动态停留使用 edgehide 完整序列，不退回单张 peek 末帧；检查左右方向、连续循环和窗口位置固定。本地形象包预算与跨机/游戏素材预算各自验收，不能把本地成功当作网络传输通过。

**已发生的坑**：独立 Node/Electron 进程向同一资料目录写库，当前客户端的注册表与事件仍停留在旧状态，最后错误地让用户重启。后台离线写库只能作为材料准备；不构成在线导入完成。不要以手改 config、清缓存、重启、切身份弥补缺失登记。若已经离线写入，在原客户端重新走导入入口及已授权应用，实际确认，不再开共享资料的第二实例。

## 游戏：新导入立即可用，目录更新不打断旧局

- 单 HTML 通过当前客户端入口导入后立即预览/打开。改过源码不代表缓存中的 HTML 已更新；重建并重新导入新成品，核对实际打开/发送的 SHA-256。导入会重新经过权限检查，不直接改授权存储。
- 加入游戏库时，先保证运行实例真正读取的素材源/内容摘要缓存齐全；再在同目录以临时文件原子替换完整候选目录。必须保留其他作品并校验封面解码和完整资源回执。只有 HTML/封面材料或仅修改其他 checkout 都不算完成。
- 已打开游戏列表应发现新增、同 id 标题/封面更新；新选择准备的是新摘要。已经准备的附件、聊天记录和运行中的游戏继续绑定旧字节，不能暗中替换、强刷页面、丢草稿或重置对局。新版本从新导入/新打开进入；需要游戏内迁移时由作品另行定义。
- 不修改签名安装包或只读 ASAR。若旧客户端没有导入/热加载能力，报告确切兼容缺口，不能把「请重启」作为本轮完整交付。代码升级和内容导入是两个流程；不得承诺无需升级的旧二进制会凭空获得新能力。

## 已打开 Web 跟随换装

新 Web 使用 [完整动作读取与订阅](host-animations.md)，在页面整个生命周期内跟随外观变化。订阅先于首次读取，变化后重新取目录并校验分页签名，完整解码后一次替换显示；保留角色位置、规则、比分、草稿和对局。不能只在初始化读一次，也不要要求用户重启宿主或重新开局来更新自己新做的 Web。

旧作品未实现订阅时明确它的限制；不要将本技能更新描述为已经自动迁移所有旧游戏。联网作品使用 Room/Looks 维护形象交换，按版本签名去重并遵守素材预算；本地订阅本身不证明对端也已更新。读取 PNG 动作不为实时 3D 模型创建骨架。

## 最小完整证据

- 记录目标客户端、进程标识、内容 SHA-256、导入返回 id/摘要；同一进程导入前后列表及实际画面发生预期变化，生效步骤中没有重启。
- 形象：真实文件入口、更新后再导入、同进程应用、实际新帧、重复/损坏包反馈、身份保持。游戏：同进程 HTML 打开/新摘要、库卡片与封面热刷、旧附件/对局固定、中文草稿跨刷新保留。Web 换装：已打开页面跟随两次变化，位置/进度保留，拒绝授权/读取失败可见并可重试，关闭释放订阅。
- 自动验收使用隔离 userData/端口，首次绘制前隐藏，CDP 真正输入与后台截图；只结束本轮进程。另用新实例证明持久化，不能混入「即时生效」证据。缺环境则明确待验，不能用“文件已复制”代替。

公开提交只含流程、公共 API、匿名夹具与结果摘要；不附用户素材、资料目录、账号、凭据、宿主源码/安装包或下载/更新位置。
