# 在线导入与动作复用交付 · 2026-10-16

## 目标与已确认边界

在最新上游基础上完善游戏/形象制作技能：已授权的制作接入必须包括当前客户端导入、按授权应用/打开、同进程新内容生效；不要求用户重启。仅请求文件时仍可独立交付。保留已验收动作、原分辨率和动态探头停留；游戏库更新不破坏编辑草稿、已准备附件与进行中的对局。新 Web 跟随换装并复用完整动作帧。

基线为上游 main `a6d5963`；上一轮 PR #1 已于10月15日合并。先将 fork/main 从 `cce70cb` 快进至该上游基线，再开发本轮。候选技能包版本0.2.2，与参考 pet-kit/宿主版本分别记录。

## 改动地图

- SKILL、README/INSTALL 与导入/SDK/验收参考统一路由到 live-import 与 host-animations；制作结果、当前客户端登记、换上/打开、实际画面分别验收。
- animation-bank.mjs 实际复用 character.getAnimationCatalog/getAnimation 的原始帧与 watch/next/unwatch，处理分页签名、按字节截页、有限重试、可选动作失败、原子换装与订阅释放。仅在作品内绘制与移动角色。
- 插件 pet.pet.getAnimations/playAnim 与普通 HTML 只读动画接口分别说明；未新增桌面本体位移接口，不以 walk 播放承诺窗口移动。
- 具名 test:animations 进入 npm test/test:delivery；test:host-live-import 进入显式 test:host:delivery。普通便携门禁不依赖私有宿主，真实宿主门缺依赖则失败。

## SDK与发布范围

宿主只读核对，不修改SDK；公开类型 `4abb17b`、脚手架 `ca71e03`、市场 `31b6655` 已包含完整动作契约，因此本轮三仓无需修改，也没有npm/宿主/市场发布。完整帧接口仍experimental，已发布最低宿主版本未确定。新指南与适配器不自动迁移旧starter、旧游戏或pet-kit副本；具体作品按所选版本接入并验收。
